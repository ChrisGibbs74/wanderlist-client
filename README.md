# WanderList

A travel tracking app for study abroad students to log, rate, and reflect on European countries they have visited.

## Live URLs

- **Front-end:** https://chrisgibbs74.github.io/wanderlist-client/
- **Back-end API:** https://wanderlist-server-production.up.railway.app

## GitHub Repositories

- **Front-end:** https://github.com/ChrisGibbs74/wanderlist-client
- **Back-end:** https://github.com/ChrisGibbs74/wanderlist-server
- **Milestone 1 Docs:** https://github.com/ChrisGibbs74/wanderlist

## Features

- Register and log in with a personal account
- Browse all European countries as cards
- Log a visit to any country with ratings for Overall, Cost, Nightlife, and Sightseeing
- Record how many times you have visited a country and write personal notes
- View, edit, and delete your personal travel list
- Public leaderboard showing most visited and highest rated countries across all users

## Tech Stack

| Layer | Technology |
|---|---|
| Front-end | Vue 3, Vite, Pinia, Vue Router |
| Back-end | Node.js, Express.js |
| Database | MongoDB Atlas, Mongoose |
| Authentication | JWT |
| Deployment | GitHub Pages (front-end), Railway (back-end) |
